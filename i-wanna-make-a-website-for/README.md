# A Little World for Kochuu

A mobile-first romantic scrapbook made with plain HTML, CSS, and JavaScript.

## Open it

Open `index.html` in a browser. The photos and proposal artwork are stored locally in `assets/`.

## Files

- `index.html` contains the page sections and personal letter.
- `styles.css` contains the scrapbook styling and responsive layout.
- `script.js` contains the interactions and animations.
- `assets/photos/` contains the selected scrapbook photos.
- `assets/proposal-mountain.png` contains the proposal illustration.

The temporary local key-setup folder is excluded from version control.
